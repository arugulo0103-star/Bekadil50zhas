## Как сделать сбор ответов настоящим

### 1. Создайте Google Sheet

Создайте пустую таблицу Google Sheets.

### 2. Откройте Apps Script

В таблице: Extensions → Apps Script.

Удалите стандартный код и вставьте содержимое файла `Code.gs`.

В первой строке измените:

ACCESS_TOKEN = "CHANGE_THIS_TOKEN_2026";

например на:

ACCESS_TOKEN = "Beke50-2026-secret";

Запустите функцию `setup` один раз и разрешите доступ.

### 3. Опубликуйте Web App

Deploy → New deployment → Web app.

Параметры:
- Execute as: Me
- Who has access: Anyone

Нажмите Deploy и скопируйте URL Web App.

### 4. Вставьте URL в два файла

В `index.html` найдите:

const GAS_URL = "PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE";

и вставьте URL.

То же самое сделайте в `admin.html`.

В `admin.html` при открытии введите ваш ACCESS_TOKEN.

### 5. Опубликуйте сайт

Самый простой вариант — GitHub Pages.

Загрузите `index.html`, `admin.html` и при желании остальные файлы в GitHub repository.
В Settings → Pages выберите публикацию из ветки `main`.

После публикации GitHub выдаст ссылку вида:

https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/

Сайт будет доступен гостям с телефона.
